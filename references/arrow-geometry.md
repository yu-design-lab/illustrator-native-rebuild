# 箭头几何与连接检查

用于原生路径构造的直箭头、曲线箭头与分体头部。先匹配参考图的箭型、尺寸和尖端目标；以下三角头公式是常见实心箭头的构造方法，不用于将其他箭型强行替换为三角形。

## 同一基准生成箭身和头部

在参考图坐标系（x 向右、y 向下）中定义：

- `T`：最终可见尖端的目标位置。
- `u = (ux, uy)`：箭身指向尖端的单位方向向量。
- `n = (-uy, ux)`：垂直于 u 的单位向量。
- `L`：头部长度；`W`：头部总宽度，二者为正数。
- `B = T - L*u`：头部底边中点。
- `V1 = B + (W/2)*n`、`V2 = B - (W/2)*n`：底边两端。

用 `T, V1, V2` 构造闭合填充路径。头部中轴由 B 指向 T，与 u 一致。头部和箭身共用 `origin`、`scale`；不要对头部额外取反 y 或另用一套旋转角度，以免造成二次翻转和错位。

直箭身沿该中心线到达底边附近，并在头部内部结束，例如 `E = B + d*u`，其中 `0 < d < L`。d 根据描边宽度、端帽和头部形状选择，不能固定用于所有尺寸。终端描边的完整外轮廓必须被头部覆盖，同时在底边处有足够重叠避免抗锯齿白缝。越靠近尖端，三角头部越窄，因此不能把 E 设为 T，也不能只检查中心点是否在三角形内部。

例如：`T=(100,50)`、`u=(1,0)`、`L=20`、`W=16`，得到 `B=(80,50)`、底边两点 `(80,58)` 与 `(80,42)`。若箭身宽为 4 且终端外轮廓能被头部覆盖，可先取 `E=(82,50)` 再检查实际导出；不能将宽为 4 的箭身延伸至 `(100,50)`，否则尖端附近可能露出矩形描边。

## 曲线箭头沿末端切线对齐

设计中心曲线时，设最后一段三次贝塞尔的终点为尖端目标 `P3=T`，终点前的控制点为 `P2`。非退化情况下，末端方向为 `u = normalize(P3-P2)`，不是 `normalize(P3-P0)`。

若 `P3=P2`，使用曲线趋近末端时的非零方向：可检查更前面的控制点或取接近终点的导数。整段退化或存在尖点而无法确定方向时先修正曲线，不能随意给头部一个角度。

确定头部后，将实际绘制的箭身收短到头部内部；需要时局部调整最后一段及控制柄，使连接处切线仍与头部中轴一致，保留参考图的整体弯向。不要只移动曲线终点、留下不匹配的控制柄。若改变设计尖端或末端方向，重新计算头部；若仅为遮蔽连接收短箭身，不要把收短后的箭身端点误当成新的尖端目标。

## 对象实现与可见外轮廓

分体箭头使用原生 `group`：先绘制箭身，再绘制头部。常见实心头部使用统一填充、无额外描边；参考图确有边框时再保留边框，并检查它对外轮廓的影响。箭身的描边与头部的填充需使用同一色值。

端帽、描边宽度、透明度和叠放方式都会影响可见连接。当前场景格式没有 `lineCap`、`arrowhead` 或布尔合并字段，不能直接添加这些字段；需要专项控制时编写并验证本地 JSX，或将箭身与头部重建为连续的闭合填充轮廓。透明对象的重叠可能加深颜色；仅编组不会消除该现象。

## 逐支局部验收

从实际 Illustrator 文档导出，在使用尺寸与 200%–400% 下检查：

1. 头部中轴与直线方向或曲线末端切线一致，底边中点无横向偏移。
2. 尖端没有箭身继续向外伸出，肩部两侧没有多余方块、突刺或异常加粗。
3. 箭身与头部连接连续，无白缝、角度突变或重叠色块。
4. 箭头的长度、宽度、方向和指向目标与参考图相符。

对失败箭头调整同一套几何并重新导出；不能只在缩略图上看似相连就通过，也不能靠放大头部掩盖错误。这些检查由助手执行，现有 CLI 不自动识别和修正箭头错位。
